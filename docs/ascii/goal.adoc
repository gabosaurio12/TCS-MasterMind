
== Objetivo

El objetivo del proyecto es construir un port del juego de mesa MasterMind a un videojuego mulitjugador en LAN. El objetivo es que cada jugador pueda jugar en tiempo real con sus amigos en su computadora.

*El proyecto debe cumplir con las siguientes métricas:*

* <2% deuda técnica

* 0 smells

* 0 hotspots de segurdidad

* Código con complejidad ciclomática menor a 10


*Y los siguientes requisitos:*

- Registro de usuarios / jugadores

** Con verificación por código vía email

- Cambio de contraseñas

- Personalización de perfil

** Los avatares deben tener roaming para que puedan verlas más usuarios

- Inicio de sesión / jugar como invitado

- Invitación de amigos (email/código)

- Lista de amigos

** Manejar presencia: saber cuándo está conectado o cuando no

- Expulsión de jugadores por comportamiento inapropiado

** Las reglas del banneo deben ser claras y estar bien definidas

** Se expulsará a un jugador si acumula 5 reportes por uso de lenguaje inapropiado

- Lobby

- Chat colaborativo en lobby

- Unirse a la partida

- Marcadores / tabla de ganadores

- Iniciar juego

- Personalización de reglas / look and feel

- Juego mulitjugador

** Multi partida

- Soportar Inglés y Español (Internacionalización)

** Si el SO está en inglés el juego también

=== Los entregables del proyecto final son:

- Definición de artefactos de cada etapa de desarrollo

- Registro de avance en github, gitlab o bitbucket

- Pruebas

** Mínimo 300 pruebas

** Flujos normales, al menos 3 alternos y todos los flujos de excepción

=== Tecnologías a utilizar:

- Uso de framework de persistencia

** Entity Framework

- Uso de framework de comunicación en red

** WCF (Windows Communication Foundation)

- Uso de framework de UI

** WPF (Windows Presentation Foundation)

=== Prácticas que se deben seguir durante el desarrollo del proyecto:

- Prácticas seguras de escritura de código

- Seguridad en la BD

	- Se debe usar un usuario en la bd con permisos limitados

	- No se debe entrar como super admin a menos que se vayan a realizar cambios mayores

- Evitar el uso de antipatrones
