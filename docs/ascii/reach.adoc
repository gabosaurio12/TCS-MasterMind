
== Alcance

El juego incluye la implementación de funcionalidades relacionadas con el perfil del jugador como: registro, inicio de sesión, personalización de avatar, nombre de usuario y redes sociales. También funciones enfocadas al aspecto social como una lista de amigos y poder ver los perfiles de estos.

En cuanto a la jugabilidad se abarca el crear salas, entrar a partidas, un chat solo habilitado durante la sala y banneo jugadores (esto en caso de que se acumule un total de 5 reportes, los cuales se consiguen al usar lenguaje innapropiado).

Por último, el proyecto debe soportar localización (l10n).
